# Directors Room

This repository contains the scaffold for Directors Room — a Next.js + TypeScript project.

Quick start

1. Clone the repo:

   git clone https://github.com/josephpaxful-netizen/Directors-Room.git
   cd Directors-Room

2. Run the scaffold script (creates folders and base config files):

   # optional: provide PROJECT_ID
   PROJECT_ID=my-project bash scaffold-batch1.sh
   # or
   bash scaffold-batch1.sh

3. Install dependencies and start the dev server:

   npm install
   npm run dev

Notes

- The scaffold script writes package.json, tsconfig.json, next.config.mjs, tailwind.config.ts, and postcss.config.js as well as creating app/, components/, lib/, and public/ directories.
- Add any required environment variables to .env (see .env.example).
